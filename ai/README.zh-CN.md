# Praat AI 前端

本目录提供 Praat 的本地模型与 API 对话、声学测量、社区脚本执行和纠音报告。默认对话入口是 React / assistant-ui 与 pywebview / WebView2 工作台，Tk 窗口通过 `--legacy` 启动。

## 启动

安装 Python 3.10–3.12 x64（推荐 3.12），并在 Praat 的路径配置中选择解释器。安装器与路径配置共用“运行库配置（必需）”，支持逐项选择本地 wheel 和依赖包文件夹，也支持 PowerShell 联网补齐；全部运行库检测通过后才能安装或保存。路径配置的 Python 区域下方还提供 FFmpeg 路径、自动查找、实际解码检测和一键安装；FFmpeg 检测通过后才能保存路径。安装依赖：

```powershell
python -m pip install -r ai/requirements.txt
```

将 `ai/ai_config.example.json` 复制为 `ai/ai_config.json`，填写本地模型或 API 配置。现代工作台还需要 `ai/frontend/dist` 中的离线构建资产，以及 Windows WebView2 运行时。

```powershell
python ai/run_ai_chat.py
python ai/run_ai_chat.py --legacy
```

也可以从 Praat 对象窗口或声音编辑器的「前端 → 启动前端」打开工作台，从「API 配置」设置供应商、地址、模型、key、思考强度和音频能力。打开窗口或保存配置不会自行开始音频分析。修改 Python 源码后关闭窗口并重新启动。

现代数据默认位于 `ai/runtime/modern/sessions.sqlite3`；`--data-dir` 可指定现代数据目录，`--config` 可指定配置文件。`ai/runtime/conversations.sqlite3` 作为只读历史来源。恢复对话保留消息和证据，不重放对象操作，也不恢复已中断脚本。

## 模型与配置

本地服务使用 OpenAI 兼容接口，默认地址为 `http://127.0.0.1:8000/v1`。模型下载命令：

```powershell
pwsh -NoProfile -File ai/Download-Qwen35.ps1 -OutputDirectory D:\models
```

配置可指定模型路径、llama-server 路径和上下文大小；本地多轮工具调用使用 `--jinja`，应用启动的服务会设置该参数。也可通过 `PRAAT_AI_QWEN_BASE_URL` 与 `PRAAT_AI_QWEN_MODEL` 指定本地接口。

API key 来自本地配置或 `PRAAT_AI_API_KEY`；`ai_config.json` 不纳入版本控制。正常桌面入口在提交任务时允许已启用 API 配置的远程调用；其他宿主可通过 `--allow-cloud` 提供进程级授权。地址检查由宿主设置服务执行。供应商协议、工具调用和音频支持由实际模型与端点决定。

本地模型按任务获取服务租约；API 切换时 `api.stop_local_service` 控制本地服务处理。应用只停止自己拥有且未被任务占用的服务。

## 对话与测量

新对话的「分析音高与时长」「计算VOT」「获得纠音建议」按钮将预设文字追加到草稿末尾；已有文字保留，并以空行分隔。可连续点击组合需求，附件保留，点击不会自动发送。

Windows 主窗口的对象列表支持右键框选：在列表内按住右键拖动，蓝色半透明框覆盖的行会被选中，松开右键保留选区。按住 Shift 拖动可保留原有选中项并添加框内对象；拖到列表上下边缘外可自动滚动。按住 Ctrl 时使用原生列表交互，不显示蓝色框选；Ctrl 配合左键可逐项添加或取消选择。框选途中按下 Ctrl、Esc 或鼠标捕获中断会撤销本次框选。未超过系统拖动阈值的右键点击或原地长按仍打开菜单；左键、Shift 多选和键盘选择继续可用。

在 Praat 中选择 Sound 或打开声音编辑器拖出选区，再在对话里说明目标、对象或时间范围。支持对象信息、基频、强度、共振峰、VOT、TextGrid 标注、声音编辑、读入和导出等工具。点查询未给时刻时可使用选区中点；区间查询按工具支持的范围处理。明确整段请求由 API 执行层覆盖旧选区。用户指定对象时，API 守卫核对编号、类型和名称。

通用 `measure` 从 `praat_ai/measures.tsv` 取得参数，例如 `f1,f2`、`mean_pitch`、`hnr`、`cpps`、jitter / shimmer、频谱和幅度参数。多步参数使用专用工具；只在编辑器支持的量会说明限制。实际范围、分析设置、单位和未定义值见结果行，不能把估计值或缺失值当成精确测量。

VOT 按起声时刻减爆破时刻计算，支持负值与零值；自动检查预浊并单列爆破后稳定起声间隔。
清晰元音起点不由基频自动推断，可用 `vowel` 提供人工时刻；起点截断或预浊归属不清时报告
VOT 无法确定。定义、候选条件与回归入口见[测量参考](docs/measurements.zh-CN.md)。

API 流程按任务选择专业工具、直接音频观察或一般讨论。工具与报告阶段共用每轮 12 次模型请求、20 次工具尝试，供应商临时错误最多重试一次。成功测量进入报告，列出目标完成项与缺口；同目标和范围的证据可复用。本地 Qwen 使用独立的默认 3 轮、5 动作循环，其后续修改操作受关键词启发式限制。

云端对话的报告守卫核对可识别的数值、单位、量名、对象、范围与引用，并计算带输入引用的有限算式；无法核对时有限修正或交付带标记的正文。本地规划的最终模型正文与双音频可选解释共用交付证据守卫；执行循环仍各有边界。守卫不能证明自然语言解释全部正确，详见[原生 Hooks 与守卫](../docs/CURRENT-IMPLEMENTATION.zh-CN.md#测量证据与解释)。

## 音频、上下文与取消

直接音频分析能力支持预设与手动覆盖，可选验证使用随机合成短音频。只有明确不支持音频的模型或端点错误才持久纠正对应配置。验证通过不能证明细微发音判断准确，精确声学数值仍来自工具。

单个临时 PCM WAV 最多 120 秒、20 MiB；Qwen Omni 的 Base64 输入另受小于 10 MiB 限制。临时片段关闭时清理，源文件保留；异常退出后的清理会核验任务和进程身份。

上下文用量为宿主估算，供应商真实窗口可能更小。现代会话必要时生成并保存摘要，不能容纳时说明缺口。继续分析沿用原目标和已有证据；移动选区不会自行替换原材料。关闭额外 token 上限仍保留供应商窗口、工作量与应用内存限制。

停止会取消后续请求和等待，不能终止 GUI Praat 中已运行的脚本。已投递但结果未确认时，现代调度器阻止普通操作；向原进程发送的核对请求取得完整、有效快照后可恢复。核对失败不得沿用旧快照或盲目重发。独立社区脚本批处理可结束对应子进程；正式双音频分析的取消能力不能等同于对话取消。

## 插件与社区脚本

[原生插件](plugin/README.zh-CN.md) 提供 Sound 测量菜单、编辑器选区测量和启动对话窗口：

```powershell
powershell -ExecutionPolicy Bypass -File ai/plugin/install.ps1
```

`run_praat_script` 将声音副本交给独立 Praat 批处理，使用脚本表单默认值并收集输出。它看不到当前 GUI 对象列表或编辑器选区。自定义 Praat 脚本接受命令与对象引用检查，Info 输出被改写到结果文件；这些检查不构成操作系统沙箱。

Windows GUI 投递共用 `%APPDATA%\Praat\Message.txt`，多个进程或实例可能相互影响。消息文件不可写属于环境权限问题；检查实际文件权限与目标进程。`PRAAT_AI_SEND_MODE=argv` 可使用命令行投递排障，但可能激活 Praat 窗口。

## 本地纠音报告

日常菜单的 AI 纠音表单使用离线 React / WebView2 界面，分为录音对象、发音目标和分析方式；阈值与视觉解释位于“高级设置”。“使用 AI 生成解释”下方显示当前解释模型来源（云端 API 或本地模型）及模型名，跟随现有模型配置。取消或关闭表单不启动分析。

### MFA G2P 自动生成音位与配套资源

表单将语言和读音合并为“目标语言与读音”，内置英式、美式与日语配套，各自保存资源绑定。其他语言可在“纠音资源配套 → 新建语言配套”中填写名称、语言代码和读音变体，配置词典、声学模型与音位映射；保存后在纠音表单或 G2P 模型管理页选用 G2P 模型。不需要增加语言专用的生成分支。
旧配置不会被自动认作某种口音；未配置时仍可选择手动 IPA，输入普通话、日语或自定义语言代码。

1. 选择目标语言与读音，在表单的“G2P 模型”下拉框选择已登记模型；添加本地模型使用“MFA G2P 模型”管理页，并通过“用于哪个纠音配套”和“选用”指定绑定。点击“配置配套资源”配置发音词典与 **MFA 声学模型**；弹窗不重复提供 G2P 选择或添加控件。
2. 配置本地 MFA 可执行文件，或 Conda 可执行文件及已安装 MFA 的环境名；点击“检查 MFA”。本功能不自动安装环境、下载模型或训练模型。
3. 选择模型实际使用的音位体系（IPA、ARPAbet 或自定义），必要时补充 JSON 格式“原始标签 → IPA”映射，例如 `{"CUSTOM_A":"aː"}`。映射每个值必须是一个音位单位，不支持空格分隔的多音位展开。
4. 检查兼容性并保存。路径存在、静态标签检查通过和真实模型验证是不同状态；口音无法仅凭文件名或标签清单自动认证。
5. 在参考文本右侧点击“自动生成音位”。G2P 会实际运行，即使词典已经收录该词；词典读音作为额外候选。多读音按词选择后应用；人工填写过的 IPA 不会被悄悄覆盖。

G2P 模型负责 **文字 → 目标音位**，声学模型负责 **音位 → 音频时间位置**，二者不能互相替代。
读音生成只需 G2P 和可用映射；MFA 分析需要完整配套资源。英式目前只做声学对比，不能套用现有美式音位判据。
“MFA G2P 模型”管理页可先选择目标纠音配套，再点击模型的“选用”，检查并保存。纠音表单也会显示当前 G2P 模型并提供更换下拉框。取消编辑保留原绑定；保存更换模型后，旧生成记录失效，需重新生成。

自动生成按 Unicode 文字处理，不按语言白名单分支。空格和标点分隔输入单元，连续书写的文本整体交给所选模型；不猜测词界。输入经过 NFKC 和小写规范化；数字、文字或书写形式是否支持取决于模型字素表。已提供字素元数据时，缺失字符会在运行前明确提示。G2P 输出、词典补充候选、IPA 映射与选定读音的 MFA 任务交接使用同一流程。模型不支持的文本须按该模型要求改写、手动分隔或更换模型。

资源列表检查只缓存词典的唯一音位集合，按路径、大小、修改时间、创建 / 元数据变更时间和文件标识失效；生成时只保留本次输入的词典候选。两种读取都会验证完整词典，避免每次打开页面复制整本大型词典。

MFA 原始标签、ARPAbet 重音标记及词级读音与 IPA 一起保留。ARPAbet 内置转换采用常见英语对应（包括 `AH0 → ə`、`ER0 → ɚ`）；它不是口音转换器，模型特有标签或不同读音对应需通过显式映射补充。未知标签、缺词或不兼容的声学模型不能通过静默删除音位继续。
参考文本、预设或资源变化后需重新生成，或明确切换回手动 IPA；不能继续使用旧读音。
资源配置只改当前预设及其默认选择，不改旧全局活动词典/声学模型。导入是单独的资源库操作：取消编辑不会撤销已导入条目；移除登记不删除磁盘文件，受影响预设显示缺资源。

配套生成路径冻结所选资源，使用已确认读音的临时词典对齐两段音频，不修改原词典。该路径 MFA 失败会报错，不切换 wav2vec2 或比例定位；手动 IPA 路径按配置选择对齐后端。
JSON 报告保存资源快照、生成来源及词级读音；这些资源字段由解释请求过滤器排除。
**G2P 生成读音不等于识别录音实际发音**，仍没有独立音素识别或校准后的总分。

维护检查入口为 `test_mfa_resources.py`、`test_mfa_g2p.py`、`test_mfa_tutor.py`。模拟输出验证协议；实际 MFA 资源与录音对齐需分别核实。

Windows 等待 Python 参数窗口或分析任务期间，Praat 对象窗口与编辑器暂时锁定操作，并继续刷新显示；完成或取消后恢复操作。纠音窗口跟随启动它的 Praat 退出。传递给 Python 的对象编号使用真实对象 ID，Sound 导出为 16-bit PCM WAV；导出失败会停止本次运行并显示原因。

## 对比结果与归一化

“音位判据”可选择英语美式或日语标准语，均为实验性声学观察。按音类选择共振峰、频谱或相对时长，不执行独立音素识别，也没有校准后的判错阈值、总分或日语拍结构分析。JSON 不填 `profile_id` 时使用通用 DTW 路径；该路径的缺测覆盖存在限制，零差异不能证明已经评估。详情见[声学对比与音位判据](../docs/PRONUNCIATION.zh-CN.md)。

默认关闭的共振峰、相对音高和响度归一化生成独立派生曲线，不覆写 WAV、Sound 或原始测量。独立元音校准需要双方自己的多元音材料；独立音高基线需要双方同协议中性语句。缺失或不匹配时报告状态和原因，不以待测音位自拟合。方法、协议与依赖见[归一化说明](../docs/NORMALIZATION.zh-CN.md)。

真实效果核查使用[真实材料协议](../docs/NORMALIZATION.zh-CN.md#真实录音材料协议)。本地工具校验来源、人工 IPA、双方校准与材料隔离，并在相同人工边界比较原始和归一化观察；当前不计算准确率或误报率。材料是否齐备以当前清单的门禁输出为准。

分析完成后自动打开 AI 工作台中的报告会话，显示具体差异、双方数值、测量覆盖、缺测原因和已有的 AI 解释，叠加图直接显示在正文中。报告会话保留在历史记录中，可继续提问。打开或恢复报告不调用模型，也不重新执行分析。

原始报告默认保存于安装目录 `reports/` 下的独立文件夹，包含 JSON、TextGrid 和可用时的 PNG。工作台另保存报告正文、测量证据和附件副本；JSON 与 TextGrid 可从消息下方的附件入口预览。命令行 `--no-gui` 输出文件路径；工作台显示失败时也保留文件并给出路径。基础计算不要求模型；文字及图表解释为可选步骤。

`PRAAT_AI_REPORT_DIR` 可指定报告根目录，不能指向临时回导目录或其子目录。Praat 从临时目录导入 TextGrid 与 Photo 后清理该目录；JSON 不导入为对象。PNG 可用系统查看器打开或在 Praat Picture 中绘制。

`PRAAT_AI_PRAAT_EXECUTABLE` 可指定路径，具体发现与跳过策略以各测试入口为准。
缺少依赖与跳过用例需在本次结果中说明，不引用历史通过数替代当前运行。

应用里看同一份判据：纠音窗口右侧「运行环境」列出 `Praat 可执行文件 / ffmpeg / wav2vec2 模型`，
