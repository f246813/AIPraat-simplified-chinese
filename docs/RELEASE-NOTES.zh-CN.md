# AIPraat 功能与发布范围

AIPraat 提供中文 Praat、AI 对话测量工作台、标准音与学习者录音的声学对比，以及 Anki 连接。

- 对话支持云端 API 和本地 Qwen；专业数值由 Praat 工具取得，模型负责规划与解释。两条模型路径的能力和核对范围不同，详见[当前实现](CURRENT-IMPLEMENTATION.zh-CN.md)。
- 双音频支持通用声学对比和英语／日语实验性音位观察，不提供独立错音识别或校准总分，详见[判据与限制](PRONUNCIATION.zh-CN.md)。
- 可选共振峰、相对音高及响度归一化保留原始数据，真实效果须用人工材料核查。
- 安装器与路径配置检测 Python、运行库及 FFmpeg；本地模型、MFA 和配套资源由用户选择，见[安装说明](../installer/README.zh-CN.md)。

此页是发布脚本的默认功能说明，不是变更日志或测试通过证明。实际发布前核对待发布源码、前端资产、依赖、许可证及安装包，并附该产物的验证范围和已知限制。发布脚本只在显式运行和确认后上传；仓库文件存在不表示产物已重新构建或发布。
