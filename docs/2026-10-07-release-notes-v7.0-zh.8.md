# AIPraat 简体中文更新（v7.0-zh.8）

发布于 2026-10-11。

| 更新 | 说明 |
| --- | --- |
| Anki 语图插件 | 从当前卡片读取真实音频，可新增按钮或复用放大镜；支持多音频选择和时间字段定位。 |
| M4A 音频 | Windows 原生读取 AAC M4A，失败时可用 FFmpeg 临时解码。 |
| AI 工作流程 | 优化快速测量、结果解释和报告交付，改进时间范围与阶段预算处理。 |
| 语音模型管理 | 在语音词典窗口管理 Wav2Vec2 模型，更新路径配置工具与安装包。 |
