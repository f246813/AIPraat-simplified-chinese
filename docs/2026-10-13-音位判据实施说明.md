# 英语与日语音位声学判据增量

本次实现设计文档中的音类规则分发、声学观察和必要报告接入。
多语言设置面板、文本读音生成、独立识别和真实发音校准仍待后续实施。
内置判据 ID 是本次规则选择 ID，尚不代表完整语言资源预设已实现。

## 开源复用

首先检查了 OpenPronounce 的 phones.py，其中主要是独立音素识别及序列比较，
并不是现有声学曲线的音类选择器。其归一化会删除长度标记，不能直接用于日语。
本次没有复制该识别模型、总分或阈值。

实际搬入 PanPhon 固定版本 a49c242d3307864312a2701055faefa4e548501c：
完整 ipa_all.csv，以及 FeatureTable 的 Unicode NFD 归一化、音段 trie、
最长音段匹配和分段代码。读取器用标准库 CSV 替换 pandas/Segment，避免新增
整包依赖。未知符号不静默删除。来源和 MIT 许可证随 Python 包一起打包：
[NOTICE](../ai/praat_ai/_vendor/panphon/NOTICE.md)、
[LICENSE](../ai/praat_ai/_vendor/panphon/LICENSE)。
项目新增代码负责将这些发音特征连接到现有测量、语言规则及报告。

## 使用

在“开始 AI 纠音”表单选择“英语（美式）音位判据（实验性）”或
“日语（标准语）音位判据（实验性）”。选择后更新目标语言并禁用旧式统一阈值；
仍需手填目标音位，尚无文本读音预览或按语言自动切换模型。
对齐继续使用已配置的现有 MFA/CTC 资源；没有可靠对齐时报告证据不足。
高级 JSON 请求可提供双方边界，例如：

~~~json
{
  "reference_object": 1,
  "learner_object": 2,
  "language": "ja",
  "profile_id": "ja-JP-standard-v1",
  "phonemes": [
    {"ipa": "aː", "reference_start": 0.0, "reference_end": 0.4,
     "learner_start": 0.0, "learner_end": 0.3},
    {"ipa": "n", "reference_start": 0.4, "reference_end": 0.6,
     "learner_start": 0.3, "learner_end": 0.5}
  ],
  "qwen_explain": false,
  "qwen_vision": false
}
~~~

对象编号、音位及边界应换成实际材料；边界单位为秒。
旧 JSON 没有 profile_id 时仍走旧式对比，包括历史 cmn 请求。
不匹配的语言与判据组合会报错，不静默选另一套规则。

## 当前判据

| 音类 | 适用观察 | 未执行或不适用项 |
| --- | --- | --- |
| 元音及双元音 | F1/F2 曲线对比、相对时长 | 不按 F0、响度或辅音频谱判错 |
| 擦音 | 频谱重心、高频占比、过零率、相对时长 | 不强求有声 F0 或元音共振峰 |
| 塞擦音 | 频谱重心、高频占比、相对时长 | 尚无闭塞/释放分段识别 |
| 塞音 | VOT 测量可用性、相对时长 | 现有提取器未提供 VOT，报告记录缺口 |
| 鼻音 | 频谱重心、相对时长 | 尚无独立鼻音实现识别 |
| 近音 | F2/F3、相对时长 | 不据此确认音素替换 |
| 日语促音标签 cl、长辅音 | 相对时长 | 不伪造上下文相关的单一 IPA 音 |
| 未知或未支持音段 | 未评估 | 不删除符号后冒充支持 |

两套语言规则分别标识来源和规则版本。日语长元音使用独立的
ja.long_vowel.relative_duration，促音使用 ja.geminate.relative_duration。
N/I/U 的分类适配只在日语启用，报告保留原始标签。
相对时长是目标音素时长除以相邻可靠音素的平均时长；同样语速缩放不改变比值。
它不是日语拍结构对齐，也没有经过长短音或促音判错校准。

声学特征观察必须有适用音类、双方可靠区间与足够有效帧；相对时长观察使用
目标及相邻音素的可靠边界，不要求声学帧。比例估算、定位质量低于
现有 0.70 复核界限、重叠或越界区间、缺失特征和单位不一致不支持该项观察。
该界限仅是工程上的区间筛选条件，不是发音正确概率或已校准的错误阈值。
未定义共振峰保持缺失值，JSON 使用 null；日语元音无声化不推断漏音。
所有规则为 experimental；尚未执行独立音素识别，没有替换、漏音、
增音或重音对错结论。新路径不以旧式统一阈值判错，不生成百分制总分。

## 输出

- JSON：profile_snapshot、observations、phone_assessments、check_statuses；
  新路径 errors 留空。观察附规则 ID、原始音位、双方区间、测量和方法。
- TextGrid：Target_Phones、AI_ProblemCandidates、AI_EvidenceStatus 和 AI_Observations。
  未执行的诊断和证据不足区间有明确文字，保留真实学习者边界和间隙。
- PNG：有效声学曲线或相对时长条形图；缺失帧不连线，无观察时提示查看证据状态。
- Qwen：接收观察与状态，说明放在用户材料末尾；系统提示前缀保持不变。
  解释关闭时仍生成完整基础报告。

纯时长音位（例如日语 cl）的逐音素状态为 duration_only，TextGrid 标注
“仅生成时长观察（实验性）”。其声学检查明确为 not_applicable；如果所有
音素均无适用声学特征，汇总 phone_acoustics 也为 not_applicable。
有适用特征但缺少有效测量时汇总为 not_evaluated，部分实际测量可用时为 partial。
只有实际非时长声学检查已完成才可能汇总为 observed，时长观察不计入该状态。

音频范围守卫同时适用于判据与旧式路径。任一侧区间无效或越界时跳过该
音素对，JSON 记录 insufficient_evidence 和警告，TextGrid 显示“证据不足”；
其他有效音素对仍正常比较。旧式报告不将这些未评估区间标为“未发现差异”。

判据按已有音素序列的位置配对，双方同位置音位必须一致。索引只用于标签，
不决定配对；JSON 的 phone_index 保留参考侧索引，learner_phone_index 记录
对应学习者索引。相邻区间检查按序列位置进行，不跳过不可靠音素来拼接邻居。
请求音位在对齐前取得原始 phone_index；PhoneSpec 和特征提取持续保留该编号，
对齐跳过中间或开头音素后不会给剩余音素重新编号。显式提供的编号原样保留，
旧请求按初始请求位置编号。
双方数量不一致时仍不生成判据观察；原始编号和一致的 IPA 仅用于关联报告状态，
不能启用评分。不存在可信对应时 learner_phone_index 为 null，不借用临时位置编号。
TextGrid 核对状态对应的 IPA；没有可信对应及数量不一致时的空缺区间显示“证据不足”。
同长度时的 TextGrid 和 PNG 继续使用判据的位置对应关系。

MFA 标签匹配复用 Python 标准库 difflib.SequenceMatcher；重复标签跨匹配块时
用顺序扫描补全有序子序列。可从 a s a s 保留请求的 s a s 及其原始边界，
缺少请求音位或顺序不符仍报告对齐失败。IPA 标签不再使用 ARPAbet 式尾部数字删除。
重复音位存在多个候选时，匹配可能保留较早或较晚的完整子序列；按所选区间的
真实边界进行时长观察，不因此改写音位标签。顺序扫描兜底从左向右选择候选。
这只匹配现有对齐标签，不代表执行独立发音识别。

高级 JSON 请求的预设不匹配或未知预设在启动模型前校验；命令入口返回状态码 1，
显示“无法开始 AI 纠音：…”及具体原因，不输出 Python 异常栈，也不静默更换预设。

频谱重心允许有限的零值；共振峰仍要求正值，负频谱重心不作为有效测量。
日语面板明确显示“日语拍结构：未评估”，对应 JSON 的 mora_structure 状态。
未生效的 minimum_error_duration_sec 已从请求、配置、设置面板及示例移除；
旧 JSON 和旧配置中的该字段继续被忽略，不影响其他选项。

Python 源码在新打开纠音表单时加载；本次未重新发布安装包。
安装器文件收集清单已加入 CSV，以便后续构建带上 PanPhon 数据与许可。
