# AIPraat 安装向导设计方案

日期：2026-10-14。沿用已经认可的路径配置视觉方案，保留现有三步安装流程。

## 窗口与步骤

- 默认约 900 × 780 逻辑像素。标题、三步进度和底部操作固定，中间区域负责滚动。
- 使用与路径配置一致的系统字体、白色背景、细边框、蓝色主按钮和就地状态反馈。
- 步骤显示为“选择目录 → 检查环境 → 安装程序”。当前步骤有文字、数字和蓝色强调；完成的步骤显示勾选。
- 步骤条描述进度，不提供越过环境检查的跳转操作。预览页面上方的步骤选择器只用于查看设计。

## 第一步：选择目录

保留安装目录输入、浏览、目录校验及“创建桌面快捷方式”。已有目录可直接复用。安装包内容和 Windows / CPU 要求放在简短说明中。

底部“下一步”是主操作；路径无效时在输入框下说明原因，并禁用下一步。不提前宣称目标目录有写入权限。

## 第二步：检查环境

Python、运行库状态和 FFmpeg 使用与路径配置一致的布局。运行库状态放在 Python 下方，不重复显示只读解释器路径；只保留一个“运行库明细…”入口。自动查找和从文件夹识别位于标题右侧。

| 分组 | 项目 | 操作 |
| --- | --- | --- |
| 必需环境 | Python 环境、运行库状态、FFmpeg | 浏览、运行库明细；只有存在真实安装动作时提供明确的安装按钮 |
| 可选分析工具 | llama.cpp、MFA | 程序文件浏览 |
| 本地模型与资源 | 语言模型、视觉投影、**wav2vec2 模型** | 前两项选择 GGUF 文件；**wav2vec2 选择本地模型目录** |

安装引导保留可编辑的语言模型行和 wav2vec2 模型行。两个可选分组独立展开；模型可留空。预览使用已有配置的示例，展开模型区以便检查三行布局。

底部主按钮写“开始安装”，说明点击后会开始写入程序文件。必需环境未就绪时禁用，并在对应项目旁提供原因和恢复操作。日志未保存时，只要真实检测通过，仍能开始安装。可选项沿用已有校验规则，不出现重复的“处理…”按钮。

## 第三步：安装程序

- 安装中：显示真实百分比、当前任务，以及准备 / 复制 / 保存配置 / 创建快捷方式的阶段状态。安装目录与 Python 选择列在下方；上一步、取消及主按钮在写入期间禁用。
- 安装完成：百分比 100%，标题“安装完成”，说明从桌面或开始菜单的 AIPraat 快捷方式启动。保留一个主按钮“完成”。
- 安装失败：保留真实进度，展示具体原因。目录权限错误时提供“返回选择目录”“以管理员权限重试”和“重试安装”。管理员操作只在权限错误场景出现。
- 不增加自动下载模型、自动启动程序或与既有安装流程无关的选项。

## 两种宿主的字段差异

| 字段 | 路径配置 | 安装引导 |
| --- | --- | --- |
| Python / 运行库 / FFmpeg | 保留 | 保留 |
| llama.cpp / MFA / 视觉投影 | 保留 | 保留 |
| 语言模型 | 不显示，前端模型菜单维护 | 保留可编辑 GGUF 选择 |
| wav2vec2 模型 | 不显示，语音资源管理维护 | **保留目录选择** |

后续实现共用依赖面板时，应依据宿主模式控制这些行，避免将安装引导的字段移除规则同步到路径配置，或反过来恢复路径配置中已移除的行。

## 设计依据与预览范围

沿用 `ui-ux-pro-max` 已匹配的极简专业工具风格。本次 `multi step progress` UX 查询匹配到平台通用的 `Progress Indicators` 条目，采用步骤指示与进度条，并继续使用技能内置的渐进展开、明确反馈、键盘导航及焦点规则。

HTML 为交互设计预览，所有状态和路径都明确标注为示例。可体验三步导航、运行库明细、日志未保存及失败状态；不执行真实安装。
