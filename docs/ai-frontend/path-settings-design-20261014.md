# AIPraat 路径配置窗口设计方案

日期：2026-10-14。对象：现有 C# WinForms 路径配置窗口。

## 设计目标

把窗口收敛为“必需环境”和“可选工具与资源”两组。用户先确认 Python、运行库和 FFmpeg 是否可用，再按需要展开本地工具。**删除 wav2vec2 模型整行，包括标签、状态、输入框、浏览按钮和占位高度。语言模型行继续保持移除。**

模型选择使用前端模型菜单；wav2vec2 模型使用现有语音资源管理中的 Wav2Vec2 模型页。路径窗口保存时沿用已有语音资源配置。

## 窗口结构

```text
路径配置                              自动查找  从文件夹识别…
设置程序位置，查看环境检测结果。

必需环境
Python 环境      [python.exe 路径                    ] [浏览…]
Python 3.12      ┌ 运行库已就绪 · 13/13 · CPU              ┐
                └ 全部必需运行库检测通过。 [运行库明细…] ┘
FFmpeg          [ffmpeg.exe 路径                    ] [浏览…]
已验证可用

▾ 可选工具与资源                              已配置 2 项
  llama.cpp      [llama-server.exe 路径              ] [浏览…]
  MFA            [MFA 程序路径                      ] [浏览…]
  视觉投影       [mmproj 文件路径                   ] [浏览…]
  视觉投影与语言模型的配套关系在模型菜单中确认。

───────────────────────────────────────────────────────────
✓ 必需环境已就绪                              [取消] [保存]
```

可选项已有配置时展开，全部未配置时折叠；可选路径校验失败时展开以显示错误。上图后三行只在展开时出现。默认窗口约 900 × 720 逻辑像素，最小宽度 820；正文使用系统中文字体，约 10.5 pt。标题和底部操作区固定，仅中间内容在小窗口或较大 DPI 下滚动。

## 字段与操作

| 项目 | 设计处理 | 操作 |
| --- | --- | --- |
| Python 环境 | 一行路径输入，标签下显示版本 | 浏览；只有找到真实安装包时显示“安装 Python…” |
| Python 运行库 | 放在 Python 下方，改为状态区，取消重复的只读 Python 路径框 | 唯一入口“运行库明细…”；明细中提供配置、重新检测、查看日志 |
| FFmpeg | 一行路径输入，标签下显示检测状态 | 浏览；缺失时显示“安装 FFmpeg…” |
| llama.cpp | 放入可选区 | 浏览，不提供重复的“处理…” |
| MFA | 放入可选区 | 浏览，不提供重复的“处理…” |
| 视觉投影 | 放入同一个可选区，取消只剩单项的“模型与资源”分组 | 浏览；配套关系交给模型菜单 |
| 语言模型、wav2vec2 模型 | 路径窗口中无控件、无状态、无占位 | 使用各自现有资源管理入口 |

“运行库明细…”替代当前两个打开同一窗口的入口，不在底部重复设置“运行库明细…”。自动查找、从文件夹识别作为次要操作保留在标题右侧。保存是唯一实心主按钮。

## 状态反馈

| 场景 | 就地反馈 | 保存状态 |
| --- | --- | --- |
| 正在检测 | Python 下显示“正在检测运行库…”和已完成项数；提供真实进度，保留当前输入 | 检测完成前禁用，底部写明“正在检测必需环境…” |
| 已就绪 | 运行库显示“13/13 · CPU”；FFmpeg 显示“实际音频解码通过” | 启用 |
| 检测失败 | 在运行库状态区显示明确原因及“重新检测”；保留已返回的项目结果 | 禁用，底部说明需要重新检测 |
| FFmpeg 缺失 | 该行显示“未找到可用 FFmpeg”，提供“浏览…”和“安装 FFmpeg…” | 禁用，底部指向 FFmpeg |
| 日志未保存 | 运行库仍显示检测结论，追加“日志未保存，不影响检测”；明细中的查看日志禁用 | 由真实检测结果决定，可保持启用 |
| 可选项为空 | 显示“未配置”，不使用故障色 | 不阻止保存 |
| 可选路径存在问题 | 展开对应分组，在该行说明原因和恢复操作；不另设假修复按钮 | 沿用现有可选路径校验规则 |

输入框变更后显示待检测，失焦或选择文件完成后启动检测。异步状态区保留固定高度；较长错误自然换行，避免截断。诊断日志默认收起在明细中，不占据主窗口的大文本区。

## 视觉与键盘规范

- 白色主体，少量浅灰分隔，边框清晰；不增加大面积卡片、渐变或装饰。
- 标题 22 px，正文 14 px，辅助文字 12–13 px。窗口边距 24 px，组件间距使用 8 / 16 / 24 px。
- 主色 `#245DB5`，正文 `#202938`，辅助文字 `#56647A`，成功 `#187046`，错误 `#B3261E`。状态同时使用文字和图形。
- 路径输入框和按钮高 40 px；长路径保留可编辑及横向滚动能力，并提供完整路径提示。
- 键盘 Tab 顺序按视觉顺序；焦点边框明显。Enter 保存，Escape 取消；可选组支持键盘展开。
- 标题、错误文案、按钮在 125% / 150% DPI 下换行或扩展，不固定裁切文字。

## 设计依据与交付范围

使用 `ui-ux-pro-max`，风格检索匹配 `Minimalism & Swiss Style` 中的专业工具、功能优先、清晰层级建议。布局检索未找到适合桌面设置的匹配条目，布局采用该技能内置 `quick-reference.md` 中的 `progressive-disclosure`、`field-grouping`、`error-placement`、`error-recovery`、`primary-action`、`keyboard-nav`、`focus-states` 等通用规则。当前实现为 WinForms，技能没有此技术栈条目，因此未套用其他桌面框架的实现规则。

交付为设计文档及 HTML 交互预览，预览明确标注示例数据。支持展开可选区、切换状态、打开运行库明细；不执行生产检测、安装或配置保存。本次未修改生产程序。
